# System magazynowy w Excelu

Bezpłatny szablon RAPORTY24.PL do ewidencji produktów, stanów i ruchów magazynowych.

## Zawartość

- `System_magazynowy_RAPORTY24.xlsx` — skoroszyt z panelem, raportem i przykładowymi danymi.
- `Produkty` — kartoteka; minimalny stan ustawiasz osobno dla każdego produktu w kolumnie J. Średnie zużycie dzienne wpisujesz w kolumnie K.
- `Ruchy` — rejestr przyjęć i wydań. Ilość wpisuj jako liczbę dodatnią, a typ ruchu określa kierunek zmiany stanu.
- `Pulpit` i `Raport` — podsumowanie stanu, wartości zapasu i produktów wymagających uzupełnienia.
- `Ustawienia` — krótkie wskazówki oraz przykład doboru minimum.

Arkusz zawiera dane przykładowe, które można zastąpić własnymi.
